# QuasarDB for Grafana

## Introduction

[QuasarDB](https://www.quasar.ai/) is a high performance, limitless, time series database built to handle the most demanding use cases.

This is the official QuasarDB Grafana Data Source plugin. It extends QuasarDB’s support to allow integration with the Grafana analytics and monitoring platform.

![QDB Grafana Dashboard](https://doc.quasar.ai/master/_images/grafana_dash.png)

## Installing and using the plugin

Full documentation can be found in [QuasarDB official documentation](https://doc.quasar.ai/master/user-guide/integration/grafana.html).
